# Publication inventory

Date: 2026-07-30

## Origin

This repository was initialized as a new Git repository. It did not copy the
private project's `.git` directory, objects, branches, tags, or commit messages.

## Excluded material

- Textbooks, presentations, lesson transcriptions, answer keys, and derived art.
- Student or teacher records.
- Personal and business names, domains, email addresses, and branding from the
  private project.
- Firebase, Google Cloud, storage, task-queue, and deployment identifiers.
- Environment files, API keys, tokens, certificates, and service-account data.
- Private repository documentation and migration assets.
- Existing icons, images, fonts, and binary outputs.

## Allowed material

- New code authored for this repository from the approved specification.
- Original synthetic device telemetry, audit events, questions, and documents.
- Standard protocol test vectors generated by this implementation.
- Third-party dependencies listed in `THIRD_PARTY_LICENSES.md`.

## Required checks before publication

- Inspect every tracked binary and fixture.
- Search tracked content and all local history for excluded brands and IDs.
- Run a secret scanner against history.
- Compare dependency lockfiles and container packages with the license inventory.
- Confirm the configured Git author email is appropriate for public history.
- Verify a clean clone using only documented prerequisites.
