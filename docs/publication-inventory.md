# Publication inventory

Date: 2026-07-30

## Current placement and origin

The lab was originally initialized as a new local Git repository without the
private project's objects, branches, tags, or commit messages. At explicit
human direction after Commit 5, its five focused commits were imported as
`source-trace-edge-lab/` into the original private `tatiana` repository. Phase
6 and Phase 7 continue on local branch `codex/source-trace-edge-lab`.

The standalone checkout was deleted. No remote was created, no branch was
pushed, and nothing was deployed or published.

## Publication boundary

Only this subtree is a candidate portfolio artifact. The parent repository is
not in scope and is not safe to publish: it contains product application code,
cloud/deployment configuration, migration assets, educational material, and
other private/product-specific content.

Future publication requires extracting this subtree into a clean candidate.
The parent `.git` directory, unrelated history, remotes, sibling paths,
workflows, configuration, and assets must not be copied.

## Excluded from the candidate

- Textbooks, presentations, lesson transcriptions, answer keys, and derived
  educational art from the parent.
- Student, teacher, customer, personal, or business records and branding.
- Firebase, Google Cloud, storage, task-queue, deployment, and domain
  identifiers from the parent.
- Environment files, API keys, tokens, certificates, and service-account data.
- Parent documentation, migrations, images, fonts, fixtures, and binaries.

## Intended candidate contents

- Original C++/Python/TypeScript code authored for the approved specification.
- Synthetic device telemetry, audit events, and deterministic demo keys.
- The reproducibly generated one-page synthetic PDF fixture.
- Protocol golden vectors generated by this implementation.
- Documentation and third-party inventories within this directory.

## Current checks and future blockers

The subtree has been inspected during implementation and intentionally contains
no copied private educational content. That does not replace a release scan.
Before publication, follow `docs/runbooks/publication-checklist.md`, including
clean extraction, full candidate-history secret/content scanning, binary
inspection, author review, current dependency audits, SBOM/license comparison,
clean-clone verification, and a second human review.
