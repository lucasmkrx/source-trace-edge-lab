# AI session: bounded authenticated stream protocol

- Date: 2026-07-30
- Goal: implement the v1 binary envelope, incremental parser, bounded JSON,
  CRC32, Ed25519, replay decisions, property tests, fuzz entry point, and
  byte-level specification.
- Human specification: Task 0001, Commit 3 acceptance criteria.
- AI tool: OpenAI Codex.

## Approach and risks

Codex proposed a fixed 44-byte header plus at most 4096 JSON bytes, an optional
fixed-size signature, and a final CRC. The parser uses a fixed 4212-byte array;
it reads and validates the four-byte outer length before accepting body bytes.

Risks included duplicated lengths disagreeing, integer overflow, input chunks
creating unbounded result vectors, unauthenticated messages advancing replay
state, and presenting CRC as a security property.

## Suggestions

- Accepted: fixed buffering, duplicated length checks, 32-result feed cap,
  message-specific schemas, and domain-separated Ed25519 input.
- Modified: replay evaluation is separate from parser acceptance. The parser
  verifies authenticity but only the runtime may atomically commit a new
  high-water mark with command effects.
- Rejected: none during this task.

## Verification

- The first warnings-as-errors build found ambiguous writable/const byte-pointer
  overloads and one unused test helper. Both were corrected; the rebuild passed.
- The first behavioral run passed 19 tests and failed 3 round-trip tests. The
  parser had retained the `Frame` default payload `"{}"` before appending wire
  bytes. Clearing the field before bounded append fixed the defect; this was a
  behavioral finding, not a source-string check.
- `cmake --build --preset dev && ctest --preset dev --output-on-failure`: 23 of
  23 tests passed in 0.77 seconds, including malformed frames, signatures,
  replay decisions, generated chunking, and the golden vector.
- `cmake --preset asan-ubsan`, build, and CTest: 23 of 23 passed under ASan and
  UBSan in 4.08 seconds.
- The first AppleClang fuzz link failed because the installed Xcode toolchain
  lacked `libclang_rt.fuzzer_osx.a`. Homebrew LLVM 22.1.8 was installed; the
  target then built and completed 20,000 unseeded runs.
- A normative telemetry seed was materialized from the golden-vector JSON. The
  second smoke run completed 50,000 inputs in 2 seconds, with no crash or
  sanitizer report and coverage increasing from 101 to 101 edges with feature
  coverage from 323 to 512.
- The first clang-tidy build found overly broad third-party analysis and
  actionable project findings. Analysis was scoped to product targets,
  ineffective moves were removed, and intentional two-byte wire enum width was
  documented. The final clang-tidy build completed successfully with warnings
  treated as errors.

## Residual risk

The protocol provides no confidentiality or key lifecycle. Bounded JSON can
still consume non-trivial CPU within 4096 bytes. Fuzzing and sanitizers reduce,
but do not eliminate, parser risk.
