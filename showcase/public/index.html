    AI co-working, made reviewable

    Prompts did not become trust

    Each focused commit records the human constraint, Codex contribution, observed command results, corrections, and residual risk.

    HUMAN DIRECTION

    Scope, judgment, acceptance

    • Rejected a broad 28–45 day platform proposal
    • Centered executable C++ systems evidence
    • Required truthful CRC and delivery semantics
    • Kept domain policy independent from adapters
    • Required behavioral proof before claims
    CODEX CONTRIBUTION

    Implementation, adversarial review, iteration

    • Implemented the seven focused engineering phases
    • Built malformed-input and failure-path suites
    • Diagnosed parser, subprocess, and container failures
    • Recorded modified and rejected suggestions
    • Mapped every headline claim to observed evidence
    Human correction

    Platform breadth → systems depth

    React, Firebase product work, Electron, and cloud deployment were removed from the MVP so parser, persistence, and recovery evidence could remain first-class.

    Behavioral correction

    Async subprocess → explicit lifecycle

    Deadline tests exposed child-watcher stalling. The worker moved to explicit Popen, cancellation kill, and guaranteed reap.

    Security correction

    Package failure → verified alternative

    A failed Debian signature path was not bypassed. The container moved to a digest-pinned Alpine base with signed packages.

    Evidence correction

    Assumption → real runtime behavior

    The diagnostic scenario corrected an assertion after the C++ runtime proved a connectivity event committed before an injected ACK failure.
